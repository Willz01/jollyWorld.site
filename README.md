# jollyWorld hotel website

HOTEL SITE FOR JOLLY WORLD HOTEL LIMITED

## Run
```bash
npm install
npm run dev      # local dev
npm run build    # production build in /dist
```

## Forms
Reservation and contact forms post to `ekanemwills1@gmail.com` (for now) through FormSubmit. The first time a form is submitted from the live site, FormSubmit emails an activation link to that address; click it once and every later submission arrives normally.
